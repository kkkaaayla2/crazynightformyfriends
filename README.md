# 疯狂星期X · 酒桌游戏 H5

一款面向**私人线下聚会**的轻量级网页应用，供笔者与友人自用。现有市面产品难以同时满足玩法密度、口味偏好与「零道具」场景，故以自研形式落地；**内容尺度与使用场景均限于熟人小圈，不面向公开展示或传播。**

## 核心功能

1. **抓手指**  
   收录多种玩法提示与变体，便于在桌上快速轮换、避免重复与冷场。

2. **真心话 · 大冒险**  
   题库由朋友投稿与筛选整理，侧重「好玩、接地气」，减少临时检索却过于正经或过于沉重的题目，更贴合小圈子的节奏。

3. **幼儿园 → 上高速**  
   双模式切换：温和与高能档位由同一套 UI 承载，便于按在场人员与氛围调整强度。

4. **玩点别的**  
   侧重**无需骰子、扑克等实体道具**的玩法，便于随时开局。

5. **题目贡献**  
   支持通过站内入口向题库提交新题（部署时需配置 API，详见部署文档）。**投稿密钥：** `mingtianjiuhe` —— 笔者与友人可共同维护一份「适合自己人」的题库；每一场局面的沉淀，可作为下一场的素材。
